# 每日代办清单

这是一个使用原生 **HTML、CSS 和 JavaScript** 制作的入门网页项目。它不依赖框架、软件包、数据库或账号；数据会保存在当前浏览器的本地存储中。

## 功能

- 按日期记录代办事项
- 勾选完成或删除事项
- 一键清除已完成事项
- 关闭或刷新浏览器后，清单仍会保留在本机浏览器中

## 项目结构

```
.
├── index.html   # 页面结构和文字内容
├── styles.css   # 页面外观与响应式布局
├── app.js       # 添加、完成、删除和保存代办的逻辑
└── README.md    # 项目说明
```

## 如何启动预览

本项目不需要安装依赖。最简单的方法是直接在文件管理器中双击 `index.html`，它会在浏览器中打开。

如果你想使用本地服务器预览，可以在此项目文件夹的终端中运行：

```bash
python3 -m http.server 8000
```

然后在浏览器访问：<http://localhost:8000>

## 如何停止本地服务器

回到运行服务器的终端，按下 `Control + C` 即可停止。

## 如何继续开发

1. 用代码编辑器打开这个文件夹。
2. 修改 `index.html`（内容）、`styles.css`（样式）或 `app.js`（功能）。
3. 刷新浏览器查看变化；如果使用服务器，不需要每次修改后重启它。
